# Contributing

Use [the implementation plan](docs/plans/initial-product.md) for the initial
product scope, decisions, dependencies and acceptance criteria. Its linked epic
and milestone issues own current execution state and evidence. UI interaction
examples live in [the design companion](docs/design/ux.md).

Use English repository content and Conventional Commits. Application bootstrap
must apply the supplied gitrepo TypeScript standard, standalone pnpm and the
user-approved Node-26-only CI. This documentation does not claim a completed
bootstrap or qualified application.

Implementation PRs use non-closing references for partial milestone deliveries.
Reference stable criterion IDs and exact code/input/run identities in evidence.
Close a milestone only after all applicable acceptance and dependency evidence
is current; merging a slice is not complete qualification. Requirements change
through reviewed plan changes, not a duplicated checklist in issue bodies.
